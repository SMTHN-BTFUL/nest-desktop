Opening The Nest…

The Nest lives behind Vercel sign-in protection, so the app needs a protection bypass secret to open straight to your dashboard.

  1. Open Vercel dashboard → project today-widget
  2. Settings → Deployment Protection
  3. Under Protection Bypass for Automation, copy the secret
    (create one labelled “Nest desktop app” if there isn’t one yet)
  4. Paste it below — it’s saved only on this computer
